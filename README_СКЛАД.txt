WMS Parser — запуск на складе
=============================

Windows 8 / 8.1 и запуск от администратора
------------------------------------------
Скрипты 1_УСТАНОВКА.bat, 2_ЗАПУСК.bat и 3_ОСТАНОВИТЬ.bat автоматически
фиксируют рабочую папку (даже при «Запуске от имени администратора»).
Для тихого запуска без консоли используйте Запуск_WMS.vbs — он тоже
переходит в папку проекта и вызывает venv\Scripts\python.exe напрямую.

Ежедневный запуск
-----------------
Для удобного запуска без черного окна используйте файл Запуск_WMS.vbs
(браузер откроется сам: http://localhost:8501).

Если нужен лог в консоли — запускайте 2_ЗАПУСК.bat.

Остановка сервера
-----------------
После работы обязательно остановите сервер — иначе папку нельзя удалить или переместить:
- В браузере: кнопка «Завершить работу сервера» в боковой панели слева.
- Без окна: дважды щёлкните Остановить_WMS.vbs.
- С сообщением в консоли: 3_ОСТАНОВИТЬ.bat.

Повторный запуск Запуск_WMS.vbs при уже работающем сервере просто откроет браузер
(дубликат процесса не создаётся).

Первый раз на новом ПК
----------------------
1. Распакуйте архив в папку на диске (не запускайте из zip «на лету»).
2. Установите Python 3.11+ с галочкой Add python.exe to PATH.
3. Запустите 1_УСТАНОВКА.bat и дождитесь прогрева каталога.
4. Дальше используйте Запуск_WMS.vbs.

Работа в браузере
-----------------
1. Вкладка «Обработка заказа» — можно загрузить несколько файлов сразу.
2. Вкладка «Станция ШК / Карантин» — выберите нужный заказ в списке
   и просканируйте EAN-13 для карантина и позиций без заводского ШК.
3. Скачайте Excel WMS и передайте в складскую систему.
