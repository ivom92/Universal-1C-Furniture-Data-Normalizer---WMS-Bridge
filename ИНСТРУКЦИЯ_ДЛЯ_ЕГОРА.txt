ИНСТРУКЦИЯ ДЛЯ ЕГОРА (склад Челябинск)
======================================

Что это
-------
Программа нормализует отборочные листы 1С 7.7 и готовит Excel для импорта в WMS:
колонки №, Наименование, Штрихкод, Количество, Заказчик.

Первый запуск (один раз)
------------------------
1. Распакуйте архив Warehouse_WMS_Pilot_v1.0.zip в папку на диске C:
   (например C:\WMS_Parser). Не запускайте из архива «на лету».
2. Установите Python 3.11 или новее, если его ещё нет:
   https://www.python.org/downloads/
   При установке отметьте «Add python.exe to PATH».
3. Дважды щёлкните файл «1_УСТАНОВКА.bat».
   Дождитесь сообщения об успехе (прогрев каталога может занять несколько минут).
4. Для удобного запуска без черного окна используйте файл Запуск_WMS.vbs
   (браузер откроется сам: http://localhost:8501).
   Если нужен лог в консоли — дважды щёлкните «2_ЗАПУСК.bat».

Ежедневная работа
-----------------
1. Запускайте «Запуск_WMS.vbs» (без чёрного окна) или «2_ЗАПУСК.bat».
2. В окне браузера загрузите отборочный лист (.xls или .xlsx).
3. Нажмите «Обработать заказ».
4. Проверьте вкладки «Без ШК» и «Карантин»: при необходимости просканируйте EAN-13.
5. Скачайте файл WMS и передайте его в складскую систему.

Остановка сервера (важно!)
--------------------------
Закрытие вкладки браузера НЕ останавливает программу — папка остаётся заблокированной.
После работы остановите сервер одним из способов:
- В интерфейсе: кнопка «Завершить работу сервера» в левой панели.
- Без чёрного окна: дважды щёлкните «Остановить_WMS.vbs».
- С сообщением: «3_ОСТАНОВИТЬ.bat».

Повторный запуск «Запуск_WMS.vbs» при уже работающем сервере только откроет браузер.

Если что-то сломалось
---------------------
- Нажмите внизу экрана «Отправить диагностику разработчику».
- Не закрывайте чёрное окно с текстом — там видны ошибки.
- Логи пишутся в папку logs\warehouse_app.log
- Файл .env трогать не нужно (ключи Gemini и Telegram уже прописаны).

Интернет
--------
Для LLM (Gemini) нужен интернет. Если сети нет, обработка всё равно идёт
автоматическим сопоставлением; спорные позиции попадут в карантин.

Не удаляйте
-----------
Папки: src, data, .cache, venv, scripts
Файлы: app_ui.py, .env, requirements.txt, Запуск_WMS.vbs, Остановить_WMS.vbs, 3_ОСТАНОВИТЬ.bat
Без папки .cache первый запуск будет очень долгим (повторный расчёт 12 880 позиций).
